# Glossary

**Homepage**: One User's launcher page. It has a title, an Overflow setting and an ordered list of Sections.

**Section**: A titled, ordered group of Tiles on a Homepage.

**Tile**: A link shown as an icon with a title beneath it. It has a title, a URL and an icon.

**User**: An account that signs in and owns exactly one Homepage.

**Admin**: The first User created on a fresh install. The Admin can create Users, reset their passwords and delete them.

**Edit mode**: The state where a User changes a Draft of their Homepage instead of viewing it.

**Draft**: A User's unpublished copy of their Homepage. Edit mode changes it, "Done" publishes it, and "Cancel" discards it. An abandoned Draft is resumed the next time the User enters Edit mode.

**Overflow**: A Homepage-wide setting for rows of Tiles wider than the screen. `wrap` continues them on the next line, and `scroll` lets them scroll sideways.
